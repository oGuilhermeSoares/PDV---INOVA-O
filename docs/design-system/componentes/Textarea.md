# Textarea

Textarea nativo, com o mesmo estilo de campo (`fieldStyles`) e redimensionamento vertical. Fica em [`src/components/ui/Textarea.tsx`](../../../src/components/ui/Textarea.tsx).

**Quando usar:** em descrições e mensagens, dentro de um [Field](Field.md). Use o placeholder para um exemplo do que se espera: "Ex.: O relatório de novembro já está no portal."

**O que você passa:** as props nativas de `<textarea>`, como `rows`.
